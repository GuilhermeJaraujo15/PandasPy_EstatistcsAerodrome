# Flight Data Analysis with Emphasis on Local Weather Conditions

This project performs an Exploratory Data Analysis (EDA) to answer questions regarding the relationship between weather conditions and flight operations during a single seasonal period.

It uses Python with libraries such as Pandas, NumPy, Matplotlib, Seaborn, and SciPy to process and analyze flight data from July in the years 2023, 2024, and 2025, together with weather data corresponding to the same dates.

> **Note:** all data used in this project is fictional and was created exclusively for educational purposes and for practicing Python and its data analysis libraries.

---

## How to Run Locally

This project does not include a web interface. The analysis is executed locally through the `veranalise.py` script, which processes the CSV files available in the repository and generates statistical results and charts.

### 1. Clone the Repository

```bash
git clone https://github.com/GuilhermeJaraujo15/PandasPy_EstatisticsAerodrome.git
cd PandasPy_EstatisticsAerodrome
```

You can also download the project directly from GitHub by selecting **Code > Download ZIP**.

### 2. Check Python

The project uses **Python 3.12+**.

```bash
python --version
```

On some systems, you may need to use:

```bash
python3 --version
```

### 3. Install the Dependencies

```bash
pip install pandas numpy matplotlib seaborn scipy
```

Or, if your system uses `pip3`:

```bash
pip3 install pandas numpy matplotlib seaborn scipy
```

### 4. Run the Analysis

```bash
python veranalise.py
```

Or:

```bash
python3 veranalise.py
```

The script automatically uses the following files:

```text
voos_2023.csv
voos_2024.csv
voos_2025.csv

meteorologia_aeroportos_2023.csv
meteorologia_aeroportos_2024.csv
meteorologia_aeroportos_2025.csv
```

Statistical results are displayed directly in the terminal, while the generated charts are stored in:

```text
img/
```

No database, web server, or external services are required to run the project.

# Script Output Explanation

Below is an interpretation of each output block generated by the `veranalise.py` script. This information helps explain the results and assess the validity of the conclusions.

## Initial Message

```text
Data loaded:
  Flights: 3720 records
  Weather: 4650 records
```

- **Flights:** 3,720 records (3 years × 31 days × 40 flights/day).
- **Weather:** 4,650 records (3 years × 31 days × 10 airports × 5 time slots).
- **Data injection:** the script injected 177 synthetic records (5% of operated flights) with visibility values ranging from 500 to 4,500 m to enable the analysis of the **"Very low (<5000m)"** visibility range.

---

## Average Delay by Visibility Range

```text
--- Average delay by visibility range ---
                           mean  median  count        std
faixa_visibilidade
Muito baixa (<5000m)  29.384181    29.0    177  12.991666
Baixa (5000-10000m)   30.053104    30.0   2787  12.323093
Normal (>10000m)      24.371380    23.0    587  14.471169
```

- **mean:** average delay, in minutes, for each visibility range.
- **median:** the central value of the distribution, which is less sensitive to extreme values.
- **count:** number of flights in each range.
- **std:** standard deviation; the higher the value, the greater the dispersion of delays.

**Interpretation:** flights under normal visibility conditions (>10,000 m) have an average delay of 24.4 minutes, while flights under very low visibility conditions (<5,000 m) have an average delay of 29.4 minutes — a difference of approximately 5 minutes.

The intermediate range (5,000–10,000 m) has the highest average delay, at 30.1 minutes.

---

## ANOVA Test (p-value)

```text
ANOVA p-value: 0.0000 (significant if p < 0.05)
```

- **Definition:** the *p-value* represents the probability of observing differences between the group means under the null hypothesis that the group means are equal.
- **Conclusion:** since the value is below 0.05, the hypothesis that all group means are equal is rejected.

Therefore, the data indicate a statistically significant association between visibility ranges and the observed flight delays.

---

## Correlation Between Precipitation and Cancellations

```text
--- Correlation between accumulated precipitation and cancellations ---
r = 0.018, p = 0.8064
```

- **r (Pearson correlation coefficient):** 0.018 — a value very close to zero, indicating no relevant linear relationship between accumulated precipitation and the number of cancellations.
- **p-value:** 0.8064 — well above 0.05, indicating no statistical significance.

**Interpretation:** in the analyzed dataset, the amount of rainfall does not show a statistically significant linear relationship with flight cancellations. Other factors, such as wind, visibility, or operational decisions, may be associated with these events.

# Explicação da Saída do Script

Abaixo está a interpretação de cada bloco de saída gerado pelo script `veranalise.py`. Essas informações ajudam a compreender os resultados obtidos e a validade das conclusões.

## Mensagem Inicial

```text
Dados carregados:
  Voos: 3720 registros
  Meteorologia: 4650 registros
```

- **Voos**: 3.720 registros (3 anos × 31 dias × 40 voos/dia).
- **Meteorologia**: 4.650 registros (3 anos × 31 dias × 10 aeroportos × 5 horários).
- **Injeção de dados**: o script injetou 177 registros sintéticos (5% dos voos realizados) com visibilidade entre 500 e 4.500 m para permitir a análise da faixa **"Muito baixa (<5000m)"**.

---

## Atraso Médio por Faixa de Visibilidade

```text
--- Atraso médio por faixa de visibilidade ---
                           mean  median  count        std
faixa_visibilidade
Muito baixa (<5000m)  29.384181    29.0    177  12.991666
Baixa (5000-10000m)   30.053104    30.0   2787  12.323093
Normal (>10000m)      24.371380    23.0    587  14.471169
```

- **mean**: atraso médio, em minutos, para cada faixa.
- **median**: valor central da distribuição, menos sensível a valores extremos.
- **count**: quantidade de voos em cada faixa.
- **std**: desvio padrão; quanto maior o valor, maior a dispersão dos atrasos.

**Interpretação:** voos com visibilidade normal (>10.000 m) apresentam atraso médio de 24,4 minutos, enquanto voos com visibilidade muito baixa (<5.000 m) apresentam média de 29,4 minutos — uma diferença de aproximadamente 5 minutos.

A faixa intermediária (5.000–10.000 m) apresenta o maior atraso médio, com 30,1 minutos.

---

## Teste ANOVA (p-value)

```text
ANOVA p-value: 0.0000 (significativo se p < 0.05)
```

- **Definição:** o *p-value* representa a probabilidade de as diferenças observadas entre as médias dos grupos ocorrerem ao acaso.
- **Conclusão:** como o valor é inferior a 0,05, rejeita-se a hipótese de que todas as médias sejam iguais.

Portanto, os dados indicam uma associação estatisticamente significativa entre as faixas de visibilidade e os atrasos observados.

---

## Correlação entre Precipitação e Cancelamentos

```text
--- Correlação precipitação acumulada vs cancelamentos ---
r = 0.018, p = 0.8064
```

- **r (coeficiente de Pearson):** 0,018 — valor muito próximo de zero, indicando ausência de relação linear relevante entre precipitação acumulada e número de cancelamentos.
- **p-value:** 0,8064 — muito acima de 0,05, indicando ausência de significância estatística.

**Interpretação:** nos dados analisados, a quantidade de chuva não apresenta relação linear significativa com os cancelamentos. Outros fatores, como vento, visibilidade ou decisões operacionais, podem estar associados a esses eventos.
